# sync SKILL 蓝图

## Metadata
- title: sync - 同步影子蓝图
- type: skill
- summary: 代码修改后，将有意义的实现变化按轻重分层同步回影子蓝图，保持架构意图层与代码层的一致性

## 核心职责

1. **识别有意义的改动**：跳过格式化和纯机械调整
2. **映射蓝图路径**：确定对应的蓝图文件位置
3. **判断同步深度**：普通文件轻量同步，核心业务文件重点同步
4. **更新蓝图内容**：
   - 普通文件：更新 Metadata、职责摘要、变更记录
   - 核心文件：更新关键方法单元（purpose、input、output、core_steps）
5. **处理结构变化**：新增、删除、重命名带来的蓝图结构变化
6. **输出同步结果**：提示是否需要继续执行 check

## 设计原则

- 同步业务含义，不同步实现噪音
- 不因为模板里有"关键方法单元"就强行所有文件都填写
- 路径映射要稳定，保持镜像结构可信
- 历史蓝图过旧时，优先修正核心职责和关键方法
