# check SKILL 蓝图

## Metadata
- title: check - 检查蓝图一致性
- type: skill
- summary: 检查蓝图与代码是否一致，识别架构漂移、说明缺失或方法描述过期，生成详细的检查报告

## 核心职责

1. **识别检查范围**：指定文件/目录，或检查本次会话修改的所有文件
2. **验证蓝图存在性**：检查代码文件是否有对应蓝图，识别缺失和孤立的蓝图
3. **对比内容一致性**：
   - 提取代码关键信息（类名、方法列表、方法签名、依赖关系）
   - 提取蓝图关键信息（方法单元、依赖关系）
   - 对比差异（新增/删除/变更的方法、签名不一致、依赖不一致）
4. **检查元数据完整性**：验证 Metadata、方法单元字段、变更记录
5. **生成检查报告**：
   - 一致性状态（通过/警告/失败）
   - 严重问题列表（必须修复）
   - 警告问题列表（建议修复）
   - 修复建议
   - 一致性评分

## 检查规则

### 严重问题（必须修复）
- 代码文件存在但蓝图文件缺失
- 蓝图中的方法在代码中已删除（架构漂移）
- 蓝图元数据缺失（title、type、summary）

### 警告问题（建议修复）
- 代码中新增方法但蓝图未更新
- 方法签名变化但蓝图未同步
- 依赖关系变化但蓝图未更新
- 变更记录超过 30 天未更新

### 可忽略问题
- 代码格式化差异
- 注释变化
- 私有方法/内部实现细节

## 设计原则

- 检查不应该阻塞工作流，只提供建议
- 关注架构意图层面的一致性，不是代码细节
- 允许合理的滞后（小的重构不需要立即同步蓝图）
- 如果发现大量不一致，建议重新运行 init
