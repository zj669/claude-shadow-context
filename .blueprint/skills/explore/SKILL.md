# explore SKILL 蓝图

## Metadata
- title: explore - 探索代码上下文
- type: skill
- summary: 探索和熟悉代码上下文，从业务入口快速收敛到最相关的蓝图与代码。适用于任何需要理解代码的场景

## 核心职责

按固定顺序收敛最小上下文：**根入口 → 业务入口 → 精准蓝图 → 必要代码**

1. **理解探索目标**：判断业务域和关注范围
2. **读取根入口**：从根 CLAUDE.md 确认阅读入口
3. **定位蓝图**：只读取最相关的 1~3 个蓝图文件
4. **补看代码**：只有蓝图不足时，再补看少量代码
5. **输出上下文**：业务域、蓝图入口、关键方法摘要、推荐代码落点

## 使用场景

- 用户想熟悉项目整体结构
- 用户询问某个功能在哪里实现
- 用户需要理解某个模块的职责
- 分析需求、修复问题或开发功能前
- 任何需要理解代码上下文的时候

## 设计原则

- 不直接加载整个 `.blueprint/`
- 不跳过根入口直接散搜代码
- 蓝图足够时，不继续扩读
- 找不到蓝图时，提示先执行 `/bluefirst-plugin:init`
