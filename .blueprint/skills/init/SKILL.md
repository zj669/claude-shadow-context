# init SKILL 蓝图

## Metadata
- title: init - 影子蓝图初始化
- type: skill
- summary: 为业务项目初始化蓝图优先结构，通过探索、确认、生成、校验六个阶段，建立严格按照模板的蓝图镜像

## 核心职责

按六个阶段完成初始化：**探索项目 → 交互确认 → 评估复杂度 → 生成 CLAUDE.md → 生成蓝图 → 校验**

1. **探索项目**：理解项目结构、技术栈、业务模块
2. **交互确认**：遇到不确定的业务逻辑询问人类
3. **评估复杂度**：判断是否需要拆分 CLAUDE.md（超过 500 行）
4. **生成 CLAUDE.md**：只在真实代码目录，包含"先看蓝图"提示
5. **生成蓝图**：严格按照模板，1:1 复刻代码文件（不包括 CLAUDE.md）
6. **校验**：确保生成结果符合规范

## 关键规则

- **探索优先**：先理解项目，再生成蓝图
- **交互确认**：遇到不确定的业务逻辑必须询问人类
- **模板约束**：严格按照 `templates/blueprint-file.md` 生成，不能自作主张增加内容
- **分层处理**：核心业务文件有关键方法单元，普通文件只有 Metadata + 变更记录
- **CLAUDE.md 位置**：只在真实代码目录（src/、app/ 等），不在 .blueprint/ 目录
- **复杂度控制**：超过 500 行需要按业务模块拆分 CLAUDE.md
- **镜像优先**：保持"代码路径 → 蓝图路径"稳定可信

## 设计原则

- 业务优先，不按包结构机械铺开
- 镜像优先，保持路径映射稳定
- 核心文件一步到位，普通文件轻量处理
- 严格模板约束，不能额外新增内容
