# init - 影子蓝图初始化

## 概述

`init` 用来把项目初始化成”可直接开始分析”的蓝图优先结构，而不是只创建空文件。

单文件蓝图默认基于以下模板生成：

- 普通文件只有 `Metadata` + `变更记录`
- 核心业务文件才有 `Metadata` + `关键方法单元` + `变更记录`
- 严格按照模板生成，不能自作主张增加内容

## 执行步骤

### 阶段 1：探索项目（理解结构和业务逻辑）

1. 扫描项目目录结构，识别主要代码目录（src/、app/、lib/、packages/ 等）
2. 识别项目类型（Web 应用、API 服务、库、CLI 工具等）
3. 识别技术栈（语言、框架、主要依赖）
4. 分析业务模块划分和核心业务文件
5. 识别配置文件、工具文件、业务文件的分布

### 阶段 2：交互确认（遇到不确定的业务逻辑询问人类）

6. 对于不确定的业务逻辑，使用 AskUserQuestion 询问用户确认
7. 确认哪些是核心业务文件（需要生成关键方法单元）
8. 确认业务模块的划分是否合理
9. 确认是否有特殊的目录需要排除或特别关注

### 阶段 3：评估复杂度（判断是否需要拆分 CLAUDE.md）

10. 评估项目业务复杂程度（文件数量、业务模块数量、代码行数）
11. 预估根 CLAUDE.md 的内容长度
12. 如果预估超过 500 行，按业务模块拆分 CLAUDE.md
13. 确定 CLAUDE.md 的层级结构（根 + 模块）

### 阶段 4：生成 CLAUDE.md（只在真实代码目录）

14. 在项目根目录生成 CLAUDE.md，包含：
    - 项目概述
    - 核心架构说明
    - **”先看蓝图再进代码”的明确提示**
    - 业务模块导航
    - 蓝图使用说明
15. 如果需要拆分，在各业务模块目录生成 CLAUDE.md，包含：
    - 模块职责说明
    - **”先看蓝图再进代码”的明确提示**
    - 模块内文件导航
    - 关键蓝图文件指引
16. **重要**：CLAUDE.md 只在真实代码目录（src/、app/ 等），不在 .blueprint/ 目录

### 阶段 5：生成蓝图文件（严格按照模板）

17. 在 .blueprint/ 下按真实代码路径建立镜像结构
18. 为每个代码文件生成对应蓝图（1:1 复刻，**不包括 CLAUDE.md**）
19. 蓝图文件严格按照上述"蓝图文件模板"生成：
    - **核心业务文件**：`Metadata` + `关键方法单元` + `变更记录`
    - **普通文件**：`Metadata` + `变更记录`（不包含关键方法单元）
20. **关键方法单元**的生成规则：
    - 只记录核心业务逻辑方法
    - location：方法位置（ClassName.methodName() 或 functionName()）
    - purpose：存在目的（解决什么业务问题）
    - input：参数类型和说明
    - output：返回值类型和说明
    - core_steps：核心步骤（关注业务逻辑，不是代码细节）
21. **严格约束**：不能自作主张增加模板之外的内容（如依赖关系、调用链、性能指标等）

### 阶段 6：校验（确保生成结果符合规范）

22. 校验所有 CLAUDE.md 是否包含”先看蓝图”提示
23. 校验 CLAUDE.md 只在真实代码目录，不在 .blueprint/ 目录
24. 校验蓝图文件是否严格按照模板生成（没有额外内容）
25. 校验镜像路径是否正确（代码路径 → 蓝图路径 1:1 对应）
26. 校验核心业务文件是否有关键方法单元
27. 校验普通文件是否只有 Metadata + 变更记录
28. 输出初始化报告：生成的文件清单、核心业务文件列表、拆分的 CLAUDE.md 列表

## 规则

- **探索优先**：先理解项目，再生成蓝图，不要盲目生成
- **交互确认**：遇到不确定的业务逻辑，必须询问人类
- **业务优先**：不按包结构机械铺开，聚焦核心业务
- **镜像优先**：保持”代码路径 → 蓝图路径”稳定可信
- **模板约束**：严格按照模板生成，不能自作主张增加内容
- **分层处理**：核心业务文件一步到位，普通文件轻量处理
- **CLAUDE.md 位置**：只在真实代码目录，不在 .blueprint/ 目录
- **复杂度控制**：超过 500 行需要拆分 CLAUDE.md

## 输出结果

- 生成的 CLAUDE.md 文件列表（根 + 模块）
- 生成的蓝图文件清单（核心业务文件 + 普通文件）
- 核心业务文件列表（包含关键方法单元）
- 镜像路径映射关系
- 初始化报告摘要
