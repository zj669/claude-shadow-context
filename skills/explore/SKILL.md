# explore - 探索代码上下文

## 概述

`explore` 不是全仓库搜索，而是按固定顺序收敛最小上下文：

**根入口 → 业务入口 → 精准蓝图 → 必要代码**

优先读取基于蓝图模板（参考 init skill）生成的单文件蓝图，从中提取 `Metadata` 和关键方法单元。

## 使用场景

- 用户想熟悉项目整体结构
- 用户询问某个功能在哪里实现
- 用户需要理解某个模块的职责
- 分析需求、修复问题或开发功能前
- 任何需要理解代码上下文的时候

## 执行步骤

1. 理解探索目标，判断业务域和关注范围。
2. 读取根 `CLAUDE.md`，确认阅读入口。
3. 如有业务目录说明文档，继续顺着它定位相关蓝图。
4. 只读取最相关的 1~3 个蓝图文件，优先看职责、关键方法、边界和上下游关系。
5. 只有蓝图不足时，再补看少量代码确认实现位置。
6. 输出最小可行上下文：业务域、蓝图入口、关键方法摘要、推荐代码落点。

## 规则

- 不直接加载整个 `.blueprint/`
- 不跳过根入口直接散搜代码
- 蓝图足够时，不继续扩读
- 找不到蓝图时，提示先执行 `/claude-shadow-context:init`

## 输出结果

- 相关业务域或模块
- 最相关的蓝图文件
- 关键方法单元摘要
- 推荐继续查看的代码位置
